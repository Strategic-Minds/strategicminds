# 06 RESPONSIVE BEHAVIOR
Desktop >=1280: cinematic hero with split editorial/data composition and multi-column signal panels.
Tablet 768-1279: reduce 3D depth and use two-column intelligence cards.
Mobile <768: single-column editorial flow, sticky compact CTA, simplified signal visualization, no custom cursor, no autoplay-heavy canvas.

Requirements:
- Minimum touch target 44px.
- No horizontal overflow.
- Hero headline remains fully visible above fold on 390x844.
- Accessible navigation drawer.
- All data visualizations preserve labels at 200% zoom.
